# Portfólio Thamyres Harmatiuk

Site editorial de portfólio UGC desenvolvido para apresentar trabalhos de beauty, haircare, skincare, bodycare e ads para marcas e agências.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

Os espaços de imagem, vídeo e métricas estão identificados no layout para substituição pelos arquivos reais sem alterar a estrutura responsiva.
